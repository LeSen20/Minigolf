# ⛳ 3D Minigolf Game

Ein interaktives 3D-Minigolfspiel mit realistischer Physik, abwechslungsreichen Bahnen und Online-Bestenliste. Erreiche das Loch mit möglichst wenigen Schlägen und knacke den Highscore!

---

## 🚀 Features

* **3D-Physik & Grafik:** Realistisches Ballverhalten und abwechslungsreiche Hindernisse.
* **Intuitives Zielen:** Einfache Touch-Steuerung zum Anvisieren und Einstellen der Schlagkraft.
* **Highscore & Cloud-Speicherung:** Online-Bestenlisten und Speicherstände via Firebase.
* **Verschiedene Level:** Abwechslungsreiche Bahnen mit steigendem Schwierigkeitsgrad.

---

## 🛠️ Tech Stack

* **Entwicklungsumgebung:** Xcode / Swift
* **UI & Rendering:** SwiftUI / SceneKit (oder RealityKit)
* **Backend:** Firebase (Firestore / Authentication)
* **Versionsverwaltung:** Git & GitHub
